# RadVision Image Enhancement Demo

RadVision is a browser-based project demo for experimenting with grayscale image enhancement. It provides split and side-by-side comparisons, zoom and pan, DICOM windowing, measurement overlays, and batch export.

## Features

- Load common raster images or a limited DICOM Part 10 subset.
- Compare original and processed images with a draggable split view or side-by-side view.
- Zoom and pan, adjust DICOM window/level, and invert MONOCHROME1 images.
- Apply CLAHE, denoising, sharpening, thresholding, and the Bone display palette.
- Use ruler, angle, ratio, and ROI tools. Distances use DICOM pixel spacing when available and pixels otherwise.
- Batch process images and download enhanced PNG files with a CSV summary.

## DICOM compatibility

The reader supports single-frame, single-sample monochrome DICOM Part 10 images with uncompressed Implicit VR Little Endian, Explicit VR Little Endian, or Explicit VR Big Endian transfer syntaxes. It reads stored-bit alignment and signed pixels, applies rescale slope/intercept and the DICOM LINEAR window function, and uses calibrated pixel spacing when present.

Compressed transfer syntaxes, color images, multi-frame objects, raw datasets without a Part 10 wrapper, DICOMDIR, DICOM writing, and DICOM network/DICOMweb services are not supported. This project does not claim complete DICOM conformance or clinical/PACS interoperability.

## 🔬 2. Pure JavaScript Algorithmic Engine (`static/js/engine.js`)

- **CLAHE (Contrast Limited Adaptive Histogram Equalization)**: Tile-based local histogram equalization with clip limiting and bilinear interpolation.
- **Global Histogram Equalization (HE)**: Full CDF-based dynamic range expansion.
- **Non-Linear Gamma Correction ($s = c \cdot r^{\gamma}$)**: Lookup-table luminance tuning for soft tissue vs dense bone.
- **Non-Local Means (NLM) Denoising**: Patch-based similarity filter for low-dose quantum mottle noise.
- **Edge-Preserving Bilateral Filter**: Spatial + photometric range Gaussian smoothing.
- **Median & Separable Gaussian Filters**: Impulse noise and speckle reduction.
- **Unsharp Masking & Laplacian Sharpening**: High-frequency boost for hairline fractures and trabecular detail.
- **Sobel Gradient Edge Map & Otsu Automatic Segmentation**: Structural edge extraction and variance-optimal bone thresholding.
- **False-Color Diagnostic Colormaps**: Calibrated LUTs for **Bone**, **Inferno**, **Jet**, **Viridis**, and **Ocean**.

## 📊 3. Quantitative IQA Metrics (`static/js/metrics.js`)

- **PSNR (dB)**: Peak Signal-to-Noise Ratio
- **SSIM**: Structural Similarity Index
- **CII**: Contrast Improvement Index ($C_{\text{enhanced}} / C_{\text{original}}$)
- **Shannon Entropy**: Information richness in bits/pixel
- **256-Bin Histogram**: Live comparative attenuation distribution rendered on HTML5 Canvas
