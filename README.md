# RadVision Image Enhancement Demo

RadVision is a local browser demo for experimenting with grayscale image enhancement. It includes split and side-by-side comparisons, zoom and pan, DICOM windowing, measurement overlays, batch export, and an optional research-only fracture-region localization model.

## Research fracture localization

The optional model is the FracAtlas YOLOv8s localization checkpoint. It draws candidate regions over the original windowed image. Its confidence values are not calibrated, and a returned region is not a diagnosis. No returned region does not rule out a fracture.

This is an experimental research feature, not validated for patient care, independent diagnosis, or clinical decision-making. It has not been validated in India. FracAtlas is a public dataset sourced from three hospitals in Bangladesh; it does not establish performance across Indian patients, multiple ages, or all bones and views. Do not use it to make patient-care decisions.

The browser sends a windowed PNG to the local service at `127.0.0.1:8765`. The service binds to loopback, disables request logs, and does not save uploaded images. The model uses CPU inference. The first run may take time while Python packages are installed.

### Enable the research model

Install Node.js and [uv](https://docs.astral.sh/uv/), then run:

```bash
npm install
npm run research:model
npm start
```

In a second terminal, run:

```bash
npm run research
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). The research panel reports whether its local model service is ready. Without these setup steps, the image enhancement tools still work and the fracture model button stays disabled.

## Image and DICOM support

- Load common raster images or a limited DICOM Part 10 subset.
- Compare original and processed images with split or side-by-side views.
- Zoom and pan, adjust DICOM window/level, and invert MONOCHROME1 images.
- Apply CLAHE, denoising, sharpening, thresholding, and the Bone display palette.
- Use ruler, angle, and ROI tools. Distances use DICOM pixel spacing when present and pixels otherwise.
- Batch process images and download enhanced PNG files with a CSV summary.

The reader supports single-frame, single-sample monochrome DICOM Part 10 images with uncompressed Implicit VR Little Endian, Explicit VR Little Endian, or Explicit VR Big Endian transfer syntaxes. It reads stored-bit alignment and signed pixels, applies rescale slope/intercept and the DICOM LINEAR window function, and uses calibrated pixel spacing when present.

Compressed transfer syntaxes, color images, multi-frame objects, raw datasets without a Part 10 wrapper, DICOMDIR, DICOM writing, and DICOM network/DICOMweb services are not supported. This project does not claim complete DICOM conformance or clinical/PACS interoperability.

## Sample images

The four included sample files are synthetic demonstrations generated by `tools/generate_datasets.js`; they are not sourced from patients or external image collections. Run the generator only when you want to recreate them:

```bash
node tools/generate_datasets.js
```
